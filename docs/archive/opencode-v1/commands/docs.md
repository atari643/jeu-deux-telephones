description: Chercher dans la documentation Android officielle hors ligne. Usage - /docs <mots clés>

Résultats de la documentation Android pour "$ARGUMENTS" :
!`pwsh tools/docs.ps1 search "$ARGUMENTS"`

Ouvre le résultat le plus pertinent avec `pwsh tools/docs.ps1 code <url>` (exemples de code)
ou `pwsh tools/docs.ps1 fetch <url>` puis réponds de façon concise, avec un extrait de code adapté au projet.
